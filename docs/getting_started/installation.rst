Installation
============

``pybuoy`` is supported on Python 3.12+ and can be installed with pip or a package manager like `uv <https://docs.astral.sh/uv/>`_:

- **with pip**: ``pip install pybuoy``

  - recommended to install any third party library in `python's virtualenv <https://packaging.python.org/en/latest/guides/installing-using-pip-and-virtual-environments>`_.

- **with uv**: ``uv add pybuoy``

  - automatically creates and manages the project's virtual environment.
